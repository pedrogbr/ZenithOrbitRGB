Zenith Orbit RGB
Controle avançado da iluminação RGB traseira do POCO diretamente pelo Android.
> **Versão atual:** `v1.0.0-beta.1`  
> **Package:** `com.zenithorbit.rgb`  
> **Status:** Beta pública
---
Sobre o projeto
Zenith Orbit RGB é um aplicativo independente criado para oferecer mais controle sobre a iluminação RGB traseira compatível do aparelho, incluindo seleção de cores, efeitos animados, ajuste de velocidade e diferentes modos visuais.
O aplicativo foi desenvolvido e testado principalmente no POCO X8 (2602BPC18G) com HyperOS 3.
> A compatibilidade com outros aparelhos Xiaomi/POCO não é garantida.

Instalação
Abra a página Releases deste repositório.
Baixe o arquivo:
`ZenithOrbitRGB-v1.0.0-beta1.apk`
No Android, permita a instalação de aplicativos de fontes desconhecidas para o navegador ou gerenciador de arquivos utilizado.
Abra o APK e conclua a instalação.
Inicie o Zenith Orbit RGB.
> O aplicativo é distribuído como APK assinado de Release.

Compatibilidade
Testado
POCO X8
Modelo: `2602BPC18G`
HyperOS 3
Outros aparelhos
O funcionamento em outros modelos Xiaomi, Redmi ou POCO pode variar porque a implementação da iluminação é específica do firmware e do hardware.
Se o seu aparelho não estiver na lista de dispositivos testados, considere o suporte como experimental.

Versão Beta
Esta é a primeira versão pública do projeto.
Mesmo após testes em dispositivo real, podem existir diferenças entre versões do HyperOS, atualizações de firmware ou estados do sistema que afetem alguns efeitos.
Caso encontre um problema, abra uma Issue informando:
modelo do aparelho;
versão do HyperOS;
efeito utilizado;
comportamento esperado;
comportamento observado;
se possível, uma gravação curta mostrando o problema.

English
Zenith Orbit RGB is an independent Android app designed to provide advanced control over compatible rear RGB lighting.
Main features include fixed colors, animated RGB effects, speed and brightness controls, custom palettes, background operation, and multiple languages.
The app has been primarily developed and tested on the POCO X8 (2602BPC18G) running HyperOS 3.
Compatibility with other Xiaomi/POCO devices is experimental and is not guaranteed.
Download the signed APK only from the official Releases section of this repository.
Current release: `v1.0.0-beta.1`
